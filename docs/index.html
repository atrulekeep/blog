  • 图片缩放预览
  • 数学公式支持
  • 评论系统集成

🚀 开始使用

# 克隆项目
git clone https://github.com/atrulekeep/vuepress-blog.git

# 进入项目目录
cd vuepress-blog

# 安装依赖
pnpm install

# 启动开发服务器
pnpm docs:dev

# 构建生产版本
pnpm docs:build
