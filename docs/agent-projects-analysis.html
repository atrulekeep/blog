分类技术

维度实现方式

规划基于预定义的检测规则分类，生成修复方案
记忆无持久化记忆，单次扫描模式

2. ditto

项目名称：ohad6k/ditto
URL：https://github.com/ohad6k/ditto
Star：137
简介：从你的 AI 编码会话日志中挖掘个人工作风格，生成 you.md 代理配置文件

核心技术栈

分类技术
语言Python（单文件实现）
平台Claude Code、Codex、Cursor、Gemini
协议Agent Skills、MCP（Model Context Protocol）

Agent 架构设计

维度实现方式
感知读取用户的 AI 编码会话日志（Claude Code、Codex 等），提取用户输入的纯文本
规划将日志分块，通过多个 worker 并行分析，再由 reducer 合并模式
记忆生成 you.md 个人配置文件，包含工作、设计、写作三个层面的规则
工具执行支持 ditto:mine（挖掘）、ditto:work（工作模式）、ditto:design（设计模式）、ditto:write（写作模式）四个命名空间技能

核心亮点与创新点

  1. 非显式规则挖掘：不依赖用户手动编写规则，而是从真实工作历史中提取"你真正的工作方式"
  2. 三重分层配置：工作、设计、写作三个独立层面，按需加载
  3. 证据驱动：每条规则都有真实会话记录作为支撑，可追溯到具体日期和会话 ID
  4. 隐私优先：所有处理可在本地完成，日志永不离开用户机器

适用场景

场景说明
个性化代理配置让 AI 助手真正理解你的工作习惯
团队协作为新加入团队的成员快速生成工作规范
跨平台迁移在不同 AI 工具间保持一致的工作体验

7. vox-director

项目名称：Alisa0808/vox-director
URL：https://github.com/Alisa0808/vox-director
Star：79
简介：将一个主题自动转化为 Vox 风格的纸艺拼贴解释视频

核心技术栈

分类技术
图像生成Google Nano Banana 2 (text-to-image)
视频生成Google Gemini Omni Flash (image-to-video)
TTSxAI TTS-v1
音乐生成MiniMax Music 2.6
视频处理ffmpeg
平台Atlas Cloud API

Agent 架构设计

topic → beat map → style bake-off → keyframes → motion → voice + music → ffmpeg assemble → final.mp4
维度实现方式
感知接收主题输入，生成叙事节拍图（beat map）
规划6 阶段流水线：节拍图 → 风格选择 → 关键帧 → 动画 → 配音配乐 → 合成
记忆beats.json 作为项目核心状态文件
工具执行Agent Skill 形式，调用 Atlas Cloud API 和本地 ffmpeg

核心亮点与创新点

  1. 端到端自动化：从单句主题到完整视频，全程自动化
  2. 两阶段人工介入：在节拍图和风格选择两个关键点让用户决策，保证质量
  3. 高质量视觉风格：还原 Vox 纸艺拼贴风格，包含撕纸边缘、半调网点等细节
  4. 真人/品牌路径：提供专门的 kling-video-o3-pro 模型处理真人内容，避免内容过滤

适用场景

场景说明

项目名称：bolivestilo/Homekit
URL：https://github.com/bolivestilo/Homekit
Star：66
简介：让任何 AI Agent 直接控制苹果智能家居

核心技术栈

分类技术
语言TypeScript
框架Node.js
协议Model Context Protocol (MCP)
桥接Apple HomeKit Framework

Agent 架构设计

AI Agent → MCP → homekit-mcp server → macOS App → HomeKit Framework → Apple Home
维度实现方式
感知通过 homekit_list_accessories 获取设备状态，homekit_get_accessory 查询单个设备
规划Agent 根据用户指令规划操作序列（如"睡前关闭所有灯"）

工具执行8 个 MCP 工具：list_accessories、get_accessory、set_accessory、activate_scene、list_scenes、create_scene、list_automations、run_automation

核心亮点与创新点

  1. 首个开源桥梁：首个打通 Apple HomeKit 和 Agent 层的开源项目
  2. 统一接口：通过 MCP 协议，任何兼容的 AI Agent 都可以调用
  3. 完整能力覆盖：支持设备控制、场景管理、自动化触发等全部 HomeKit 功能

适用场景

场景说明
智能家居语音控制通过自然语言控制智能家居
自动化场景编排让 Agent 根据时间或事件自动调整家居状态
多设备联动跨房间、跨设备的复杂控制逻辑

项目名称：jamiebeach/lisp-agent
URL：https://github.com/jamiebeach/lisp-agent
Star：54
简介：用 LISP 语言构建 AI Agent — 2026 版的"AI 语言"

核心技术栈

分类技术
语言LISP
理念符号 AI + 现代 LLM 融合

核心亮点与创新点

  1. 回归 LISP：重新审视 LISP 在 AI 领域的原生优势
  2. 符号与神经结合：将传统符号 AI 与现代 LLM 结合

适用场景

场景说明
AI 研究探索符号 AI 与神经 AI 的融合
教育学习学习 LISP 在现代 AI 中的应用

趋势洞察

1. Agent Skill 生态崛起

kill-ai-slop、vox-director、ditto 等项目均以 Agent Skill 形式交付，说明技能市场正在快速发展。这意味着：

  • 开发者可以专注于垂直领域能力的构建
  • AI Agent 平台的插件体系正在成熟
  • 技能复用成为新的开发范式

2. MCP（Model Context Protocol）成为标准

ai-openclaw-cli、Homekit 等项目均采用 MCP 协议，表明：

  • 跨平台互操作性需求迫切
  • 统一的工具调用标准正在形成
  • Agent 生态正在从封闭走向开放

3. 个性化与定制化

ditto 项目的流行反映了用户对 个性化 AI 体验 的强烈需求：

  • 不再满足于通用的 AI 助手
  • 希望 AI 能够理解并模仿个人工作风格
  • 隐私保护成为重要考量

4. 多模态内容生成

vox-director 的成功表明 端到端视频生成 是 Agent 的重要应用场景：

  • 文本 → 图像 → 视频 → 配音 → 配乐的完整流水线
  • 高质量视觉风格的自动化生成
  • 人工介入点的设计是关键

5. 物理世界连接

Homekit 项目打通了数字 Agent 和物理世界的壁垒：

  • Agent 不再局限于屏幕内
  • 智能家居是 Agent 落地的重要场景
  • 自然语言控制成为新的交互方式

优先级项目理由
⭐⭐⭐vox-director端到端视频生成的标杆，技术栈完整，商业潜力大
⭐⭐⭐Homekit首个打通 HomeKit 的 Agent 项目，场景价值高
⭐⭐⭐ditto个性化 Agent 的创新思路，解决"冷启动"问题

⭐⭐lisp-agent学术价值高，探索符号 AI 新方向
