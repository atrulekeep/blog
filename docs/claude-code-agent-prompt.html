这个思路非常棒！既然你已经把 browsershot（网络抓取）和 superpowers（包含 14+ 种结构化软件开发生命周期技能，如 TDD、根因调试、子智能体协同等）这两个强力插件配置好了，你完全可以将 Claude Code 变成一个前沿 Agent 技术的“情报侦察兵”与“架构分析师”。

为了帮你深度压榨这两个插件的潜能，我为你设计了 4 组由浅入深的实战测试提示词。你可以直接把它们贴给 Claude Code：

🧭 第一组：情报搜集（侧重触发 browsershot 联网获取一手信息）

提示词： “请使用 browsershot 访问 GitHub 的 Trending 页面（[https://github.com/trending](https://github.com/trending)）或者在 GitHub 上搜索过去 30 天内最热门的 LLM Agent 框架。找出 3 个目前在工具调用（Tool Use）或多智能体协同（Multi-Agent）上最火的新项目。在给出结论前，请先使用你的 brainstorming 技能，从『技术创新性』和『开发者痛点解决』两个维度对这三个项目进行预分析。”

  • 💡 预期效果： 强行激活 browsershot 去抓取网页，随后自动调用 superpowers 的 /brainstorm 模块进行多维度发散和深度思考。

🏗️ 第二组：架构拆解（侧重触发 superpowers 的规划与任务拆解技能）

提示词： “我想学习目前最前沿的 Agent 长短期记忆（Memory Bank） 与 自主反思（Self-Reflection）机制。请帮我构思一个能够自主分析历史对话、并自动提炼出用户长期画像的记忆 Agent 核心架构。请直接调用你的 writing-plan 技能，为我生成一份从『感知层、记忆读写、反思机制、到工具有效性验证』的详细技术设计大纲。”

  • 💡 预期效果： 越过日常聊天的水话，直接逼迫 Claude 进入高级工程师模式，调用 /write-plan（写作计划）技能生成 2-5 分钟可执行的精细化架构大纲。

🛠️ 第三组：实战演练（侧重触发 subagent 子智能体协同与复杂逻辑编写）

提示词： “我想在本地写一个微型的 Agent 框架原型，它需要支持：1. 异步并行调用多个大模型（Parallel Dispatching） 2. 基于状态机（FSM）的任务路由。请启用你的 subagent-driven-development 技能（或者 /execute-plan），在当前目录下帮我搭建起这个原型的核心代码骨架和单元测试，并确保它符合生产级别的异常处理规范。”

  • 💡 预期效果： 触发 superpowers 中极具威力的子智能体驱动开发（Subagent-driven development）。Claude Code 会在后台产生并托管并行的子会话，由它们来分别负责编写核心逻辑和测试用例，最后交由主线程汇总。

🔍 第四组：深度Debug与代码重构（针对已有 Agent 代码的痛点）

提示词： “在开发 Agent 时，大模型常常出现『幻觉调用不存在的工具』或者『陷入工具调用的死循环（Looping）』。请启动你的 systematic-debugging（系统化调试）技能，从原理上帮我分析这两种问题的根因（Root Cause Analysis），并用 Python 伪代码为我提供一套『防御性设计（Defense-in-depth）』的拦截器代码防线。”

  • 💡 预期效果： 激活 superpowers 中的 4 阶段根因追踪流程（Root cause process），它不会敷衍地给你几行偏方，而是会系统地从边界条件、防死锁、多层兜底等维度给出大厂级别的解决方案。

🛠️ 终极技巧：直接在 Claude Code 里进行技能搜索

如果你想知道自己的 superpowers 插件里还藏着哪些专门针对 Agent 开发或日常编程的武功秘籍，你可以直接在终端中输入：

  • /tools：查看当前可用的所有底层工具箱。
  • /help 或者向它提问：“请列出 superpowers 插件里目前所有可用的 / 指令和核心 skills 有哪些？”

你可以先挑第一组或第二组输入给它，看看它的“头脑风暴”和“计划生成”在终端里跃跃欲试的震撼效果！
