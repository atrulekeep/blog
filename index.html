🚀 快速开始

# 克隆项目
git clone https://github.com/atrulekeep/vuepress-blog.git

# 安装依赖
pnpm install

# 本地开发
pnpm docs:dev

# 构建生产版本
pnpm docs:build

📚 技术栈

  • VuePress 2.x - 静态网站生成器
